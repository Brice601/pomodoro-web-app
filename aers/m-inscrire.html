Vos documents

Quelle formation vous concerne ?

Les papiers ne sont pas les mêmes selon le permis. Choisissez votre cas : vous n'aurez que votre liste sous les yeux, et vous pouvez l'imprimer.

Le point qui bloque le plus de dossiers

Les photos d'identité doivent être des e-photos.

C'est la seule chose qui peut faire attendre votre dossier, et elle n'a rien d'évident : depuis que les demandes de permis passent par le site de l'ANTS, une photo de cabine ordinaire ne suffit plus. Il faut une e-photo avec signature numérique.

Concrètement, la cabine ou le photographe vous remet un code à 22 caractères : c'est ce code qui nous permet de récupérer votre photo et votre signature en ligne. Sans lui, le dossier ne peut pas être déposé.

Un doute ? Apportez ce que vous avez, on vérifie avec vous — c'est plus rapide que de refaire des photos pour rien.

Ça marche

Une cabine ou un photographe agréé « e-photo », qui vous remet un code à 22 caractères accompagné de 2 photos papier. Le code est valable 6 mois.

Ça ne marche pas

Une photo prise avec votre téléphone, une photo scannée, une photocopie de photo, ou une photo de cabine sans code numérique. Le site de l'ANTS les refuse.
